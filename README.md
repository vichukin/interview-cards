# Собес .NET — карточки

108 карточек по C#, ASP.NET Core, базам данных и паттернам. Ответы на русском и польском.

- Тап по карточке — показать ответ / вернуться к вопросу
- RU / PL на обороте — сменить язык ответа
- Свайп влево — следующий вопрос, вправо — предыдущий
- Фильтр по темам сверху; «Перемешать» — новый случайный порядок, долгое нажатие — по порядку
- В браузере: ← → листать, Пробел — перевернуть, L — сменить язык

Вопросы лежат в `src/questions.js` — их легко дописывать.

## Запуск на ноуте

    npm install
    npx expo start --web

## На телефоне без сборки (Expo Go)

    npx expo start

Поставь Expo Go из Google Play и отсканируй QR-код (телефон и ноут в одной Wi-Fi сети).

## APK для Android

    npx eas-cli@latest login
    npx eas-cli@latest build -p android --profile apk

Сборка идёт в облаке Expo (бесплатно, нужен аккаунт на expo.dev). В конце будет ссылка на .apk — открой её на телефоне и установи.

## Как приложение на телефоне (без сборки APK)

Приложение выложено на GitHub Pages и работает как PWA: открываешь ссылку в Chrome на Android,
⋮ → «Добавить на главный экран» / «Установить приложение». После первого открытия работает без интернета.

Обновить сайт после правки вопросов:

    npm run build:web
    npm run deploy

`build:web` собирает dist/ и добавляет manifest, иконки и service worker (scripts/pwa.mjs).
`deploy` пушит dist/ в ветку gh-pages.
